  map and receipt responses retain Blob handling. The shared error interceptor accepts text JSON
  alongside its existing Blob/object cases.
- Shared offsets extend beyond 500 with an integer-safe maximum. The action timeline retains its
  existing 500-offset and 100-limit bounds because it merges three source windows in memory.
- Default order pages use CreatedOn descending and Id descending before paging. Explicit sorts
  and currency-leading financial ordering are retained.
- Partner checklist ticks join the existing session-cache wipe and clear only the order-checklist
  preference prefix. Customer Live Activity teardown marks local session state inactive before
  awaiting work, cancels observers, and ends captured actual activities, including activities absent
  from the coordinator's registry. Generation and identity checks reject stale asynchronous work.
