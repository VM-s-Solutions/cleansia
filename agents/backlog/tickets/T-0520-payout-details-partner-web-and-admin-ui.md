## Context

The Angular half of the payout-details change (**T-0517** ADR → **T-0518** schema → **T-0519**
contract). Two apps: the **partner** app (the cleaner enters their own details) and the **admin** app
(staff correct them).

Today both surfaces show a single free-text IBAN input backed by a `Length(15,34)` rule. After T-0519
the contract carries a country-shaped field set with real validation and real error keys.

## Acceptance criteria

- [ ] **AC1 — the NSwag clients are regenerated by the OWNER before work starts.**
      `manual_steps: nswag-regen`; agents never run `npm run generate-*-client` (`CLAUDE.md`).
      **The PM holds this ticket until the owner confirms.** Evidence: the confirmation in the log.
- [ ] **AC2 — a cleaner can enter the CZ field set and save it**, and a round-trip reload shows what
      they saved. Evidence: the screenshot pair plus the facade spec.
- [ ] **AC3 — every server error key renders as translated text, not a raw key or a blank toast.**
      Each new key from T-0519 AC7 has its five locales in the partner app bundle **under that app's
      namespace** (the per-client error-namespace trap: the prefix differs per client, and NSwag throws
      `ProblemDetails` bare — reading `.result` alone resolves nothing). Evidence: a screenshot of each
      error state.
- [ ] **AC4 — client-side validation MIRRORS the server, it does not replace it.** No new rule appears
      only on the client. Evidence: the rule-by-rule comparison table against T-0519's validators.
- [ ] **AC5 — the admin surface can correct a cleaner's details and the action is audited.** The
      platform already has an admin-action audit log (ADR-0012); **a staff member editing a cleaner's
      bank account is exactly the action that log exists for.** Evidence: the audit entry.
- [ ] **AC6 — the value is masked where it does not need to be legible.** Whether the admin **list**
      shows account details at all is T-0519 AC10's ruling; this ticket implements it. Evidence: the
      screenshot plus the ruling citation.
- [ ] **AC7 — shared components only.** `<cleansia-button>`, `<cleansia-section>`, `<cleansia-table>`,
      PrimeNG inputs; no raw `<input>`/`<select>`/`<button>`; no inline templates or styles; `OnPush`
      on presentational components; the facade extends `UnsubscribeControlDirective`. Per `CLAUDE.md`.
      Evidence: the reviewer's confirmation.
- [ ] **AC8 — five locales on every new string** (en, cs, sk, uk, ru) in both apps' bundles. Evidence:
      the parity diff.
- [ ] **AC9 — the SECURITY gate runs.** `security_touching: true` — a financial identifier rendered in
      a browser and edited by staff. Evidence: the security verdict.
- [ ] **AC10 — `npx nx lint` and `npx nx test` green for both projects.** Evidence: the runs.
- [ ] **AC11 (Gate 0.5 leg 3)** — the AC evidence is largely visual; **no leg-1 mutation proof for the
      screenshot ACs.** State what was read vs run and what was not checked.
