## Context

The Angular half of the payout-details change (**T-0517** ADR → **T-0518** schema → **T-0519**
contract). Two apps: the **partner** app (the cleaner enters their own details) and the **admin** app
(staff correct them).

Today both surfaces show a single free-text IBAN input backed by a `Length(15,34)` rule. After T-0519
the contract carries a country-shaped field set with real validation and real error keys.

      PrimeNG inputs; no raw `<input>`/`<select>`/`<button>`; no inline templates or styles; `OnPush`
      on presentational components; the facade extends `UnsubscribeControlDirective`. Per `CLAUDE.md`.
      Evidence: the reviewer's confirmation.

- [ ] **AC9 — the SECURITY gate runs.** `security_touching: true` — a financial identifier rendered in
